# AI-book-retrieval-system

This project is a personal AI-based system designed to retrieve books using natural language descriptions instead of exact titles.

## Features

* Semantic search using embeddings
* Natural language query input
* Interactive refinement of search results
* Personalized ranking based on user behavior

## Technologies

* Python
* Sentence Transformers
* NumPy
* JSON storage

## Description

The system allows users to search for books by describing plots or characters, even when exact details are unknown. It uses embedding-based similarity search to match user input with stored book data.
